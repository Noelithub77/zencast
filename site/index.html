07 Mod formats

Only one format hands over the whole browser.

Extensions get pages. Zen mods get CSS.↗ Sine mods get the browser.↗

  1. Extension
  2. Zen mod
  3. Sine mod
How a Sine mod loads4 steps
  1. AutoConfigFirefox runs a config file from its install folder at startup, with full privileges.
  2. BootloaderSine hooks in there and finds the mods in your profile.
  3. Every windowEach mod's JS and CSS load into every browser window.
  4. UpdatesMods update from their GitHub repo.

Nothing is patched: most forks change a browser's source and rebuild it, while Sine only loads your files at startup. Scripts from outside Sine's store run only after you allow them.

08 Trust

Code in your browser sees every session.

Any mod with this reach can take your cookies and sessions.↗ Trust only code you've read↗: that's why Zencast is a template, not a product.

  1. A stranger's modFull reach: cookies, sessions, every page
  2. An auto-updating extensionOne hijacked update away↗

09 My way

Zencast is how I use my browser.

Inspired by VS Code's command palette↗ and Raycast↗: one box, type anything, all from the keyboard.

My keys

  • CtrlKFind anything: tabs, spaces, history, commands, settings
  • Alt1…9Switch space
  • AltShift1…9Send the tab to a space
  • AltPPin or unpin the tab
All my keys8 more
  • CtrlShiftNNew folder, or a subfolder
  • CtrlCOpen in a container, when nothing is selected
  • AltShiftTTab in a throwaway container
  • AltShiftCMove the tab to a container, session and all
  • AltShiftWWipe a site's data and history
  • CtrlSpaceFChords: move to a folder, space or essentials
  • Ctrl.Give any command, tab or site its own key
  • Ctrl/See every key at once
